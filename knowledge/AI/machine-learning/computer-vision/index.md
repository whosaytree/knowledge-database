# Computer Vision

## 核心理解

Computer Vision 讨论的是：如何让模型从图像或视频中识别、定位、分割和理解视觉信息。

它关注的不只是图像里有什么，还包括目标在哪里、边界如何划分、不同区域之间是什么关系，以及如何从视觉输入中提取可用于下游任务的表示。
