# Prior and Posterior

## 核心理解

Prior and posterior 讨论的是：在看到数据之前和看到数据之后，我们对某个未知量的相信程度如何变化。

在贝叶斯视角下，参数 $\theta$ 不只是一个等待被求出来的固定值，也可以被看作一个带有不确定性的随机变量。

- Prior，也就是先验，表示在观察数据之前，对参数 $\theta$ 的已有判断。
- Posterior，也就是后验，表示结合观测数据 $D$ 之后，对参数 $\theta$ 的更新判断。

因此，先验和后验不是两个孤立概念，而是一组由数据更新连接起来的概率分布。

## 贝叶斯更新

贝叶斯公式通常写成：

$$
p(\theta \mid D)
=
\frac{p(D \mid \theta)p(\theta)}{p(D)}
$$

其中：

- $p(\theta)$ 是 prior，表示看到数据之前对参数的分布假设。
- $p(D \mid \theta)$ 是 likelihood，表示如果参数为 $\theta$，当前数据出现的可能性。
- $p(\theta \mid D)$ 是 posterior，表示看到数据之后对参数的分布判断。
- $p(D)$ 是 evidence，也可以理解为归一化项，保证后验分布的总概率为 1。

这个式子的核心含义是：

$$
posterior \propto likelihood \times prior
$$

也就是说，后验来自两部分信息的结合：

- 数据通过 likelihood 提供证据。
- 先验通过 prior 提供已有约束。

## 先验是什么

先验不是随意添加的偏见，而是模型在观察当前数据之前已经带有的信息。

先验可以来自：

- 领域知识；
- 历史数据；
- 参数取值范围的合理约束；
- 对模型复杂度的偏好；
- 为了稳定小样本估计而加入的正则化假设。

例如，如果某个参数不太可能特别大，那么先验可以把较大参数值的概率设得更低。

这会影响最终后验，使模型在数据不足时不至于完全被少量样本牵着走。

## 后验是什么

后验表示看到数据之后，对参数的更新认识。

如果数据很多，并且数据提供的信息很强，后验通常会更多地受到 likelihood 影响。

如果数据很少，或者数据噪声很大，后验会更明显地受到 prior 影响。

因此，后验可以理解为：

- 不是只相信先验；
- 也不是只相信当前数据；
- 而是在两者之间做概率意义上的更新。

## 一个简单直觉

假设抛硬币 3 次，结果全是正面。

如果只看这 3 次观测，正面概率似乎应该被估得很高，甚至可能得到非常极端的判断。

但如果我们有一个比较温和的先验，认为硬币大概率不是完全偏向某一面，那么后验会把判断从极端值拉回一些。

这个例子说明：

- 数据少时，先验能提供稳定性。
- 数据多时，真实数据会逐渐主导后验。
- 后验表达的是更新后的不确定性，而不只是一个单点答案。

## 常见误解

先验不等于主观乱猜。

合理的先验应该能解释其来源，并且最好能通过敏感性分析观察它对结果的影响。

后验也不等于最终真相。

后验仍然依赖模型假设、先验选择和观测数据质量。如果模型本身假设错了，后验也可能给出误导性的结果。

## 与相关节点的关系

- `Parameter Estimation` 讨论参数估计的整体框架。
- `Maximum Likelihood Estimation` 只使用 likelihood，不显式引入 prior。
- `MAP` 可以看作在后验分布上取最大值的点估计。
- `Bayesian Estimation` 更关注完整后验分布，而不只是取一个最优参数。
- `KL Divergence` 在变分推断中常用于衡量近似后验和真实后验之间的差异。
